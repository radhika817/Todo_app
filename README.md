# Todo App v1

A simple Todo application built using Vanilla JavaScript.

## Features

- Add new tasks
- Display tasks dynamically
- Clear input after adding a task

## Concepts Practiced

- DOM Manipulation
- getElementById()
- addEventListener()
- createElement()
- textContent
- appendChild()

## Tech Stack

- HTML
- CSS
- JavaScript
